Inventory Stock Ageing

Understand how long current inventory has remained in stock with an interactive pivot report for quantities and values.

Follow current stock across five ageing buckets, from recent receipts to inventory older than 120 days.

A set-based PostgreSQL engine follows Odoo 19's remaining-stock rules without running a separate valuation pass for every product. The private snapshot refreshes each time it is opened from Inventory > Reporting > Stock Ageing.

How It Works
  1. Install the module on Odoo 19 with Inventory Valuation available.
  2. Open Inventory > Reporting > Stock Ageing.
  3. Review quantity and value by product and ageing bucket in the pivot.
  4. Filter or regroup by category, product, receipt month, or company.
  5. Choose Download XLSX from the pivot whenever an offline copy is needed.
